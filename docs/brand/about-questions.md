# 品牌故事要問貞貞的事

給之後的「品牌故事」change（獨立的「關於」頁面）用。收到回覆後，把答案記在這個檔案最下面，再開 change。

## 傳給貞貞的訊息（可直接貼到 LINE）

```
官網想加一頁「關於我們」，用你自己的話聊聊就好，不用寫得很正式，我再整理成文章 🙏

【故事】
1. 什麼時候、為什麼開始鉤織？誰教的還是自學？
2. 「織物製造所」這個名字怎麼來的？英文 JH Craft Studio 的 JH 是什麼意思？
3. 為什麼想做飲料提網、杯墊這種日常小物？
4. 挑線材、做的時候有什麼堅持？為什麼用這款棉線？

【經歷】
5. 鉤織大概幾年了？
6. 有沒有幫家人、朋友、同事做過指定顏色或用途的作品？大概幾件？

【確認】
7. 都是在台灣自己手工做的嗎？

【你決定】
8. 網站上要用「貞貞」這個名字，還是只寫品牌名就好？
9. 要放你的照片嗎？可以只拍手和作品，不露臉
10. 除了 IG，要不要放 LINE 或 Email 讓客人聯絡？

【照片】
鉤織中的手、工作桌、線材、作品的生活照，手機拍就可以
```

## 寫的時候要注意

- 只寫真的，沒有就不寫。已確認沒有擺過市集、沒有教過課（2026-10-20），網站上不提
- 幫家人朋友做的作品可以寫（真實的客製經驗），但不要寫成「客人」「訂單」，數字照實寫
- 親友的回饋可以放，要標明是家人朋友（公平會對薦證廣告的規範：推薦人和業者有關係要揭露）；不能放進結構化資料的評價（Review、評分）。真正的客人評價等開賣後再累積
- 第 7 題確認後，「台灣手作」可以寫進頁面
