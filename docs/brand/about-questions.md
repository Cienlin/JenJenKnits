# 品牌故事要問貞貞的事

給之後的「品牌故事」change（獨立的「關於」頁面）用。收到回覆後，把答案記在這個檔案最下面，再開 change。

## 傳給貞貞的訊息（可直接貼到 LINE）

```
官網想加一頁「關於我們」，用你自己的話聊聊就好，不用寫得很正式，我再整理成文章 🙏

【故事】
1. 什麼時候、為什麼開始鉤織？誰教的還是自學？
2. 為什麼想做飲料提網、杯墊這種日常小物？
3. 挑線材、做的時候有什麼堅持？為什麼用這款棉線？

【經歷】
4. 鉤織大概幾年了？
5. 有沒有幫家人、朋友、同事做過指定顏色或用途的作品？大概幾件？
```

## 寫的時候要注意

- 只寫真的，沒有就不寫。已確認沒有擺過市集、沒有教過課（2026-10-20），網站上不提
- 幫家人朋友做的作品可以寫（真實的客製經驗），但不要寫成「客人」「訂單」，數字照實寫
- 親友的回饋可以放，要標明是家人朋友（公平會對薦證廣告的規範：推薦人和業者有關係要揭露）；不能放進結構化資料的評價（Review、評分）。真正的客人評價等開賣後再累積
- 不寫「織物製造所」名字的由來：名字是請 AI 幫忙想的，沒有由來的故事，不硬編

- **英文名 JH**：兩位創作者名字的英文字首（使用者的家人）。repo 是公開的，這裡不寫名字。網站上只說「JH 取自兩位創作者名字的字首」，不寫名字、不說關係
- **網站上只寫品牌名**，不寫創作者的名字
- **不要新照片**：不拍人（包括手），也不另外拍；關於頁面只用現有的作品照片
- **聯絡方式先只用 Instagram**，不放 LINE、Email
