鉤織的網狀提網，裝得下水壺或飲料杯，提著就能出門。

不用的時候，把網子收進花朵形狀的底座，扣上木釦，就變成一朵圓鼓鼓的小花吊飾。

自己挑配色

每個提網用兩個顏色：

  • 主色：網子和花朵外圈
  • 配色：提把和花心

兩個顏色都可以從下方色卡的 22 色中挑選。
