# Proposal

## Why

後台第一階段（`add-admin-backend`）只求「能用」：列表看不到照片和價格，編輯頁是一長串欄位，儲存和發布在最底下，照片區只有文字說明，故事要按「預覽」才看得到結果。現在商品會越來越多，之後部署後也可能用手機改資料，所以先把後台整理成清楚好填的樣子。版面已經用樣稿確認過（2026-10-21，`docs/design/admin-redesign/`）。

## What Changes

- **整體**：沿用前台的色彩與字體，表單文字改用無襯線字比較好讀；「改完記得 commit＋push 資料庫」的提醒從頁尾移到頁首
- **商品列表**：每件顯示封面縮圖、價格、首頁精選排序、更新日期；標題下方顯示「幾件已發布・幾件草稿・幾件有欄位待補」；手機上改成可以整張點的卡片
- **編輯商品**：
  - 欄位分成五段：基本資料、價格與規格、購買與首頁、故事、照片
  - 側欄有「發布到前台」開關和儲存按鈕，以及「資料完成度」（例如 4 / 6），點待補項目會跳到那個欄位；待補欄位用橘色框標出
  - 有未儲存的修改時顯示提示，沒存就離開頁面會先詢問
  - 故事：加粗體、小標題、清單、連結按鈕；打字時自動預覽（桌機左右並排，手機用「編輯／預覽」切換）
  - 照片區直接顯示封面、01、02…、色卡的縮圖（仍是唯讀，照片一樣手動放進資料夾）
  - 手機上「發布＋儲存」固定在畫面底部
- **新增商品**：上方用三個步驟說明上架流程（建立草稿 → 放照片 → 補資料、發布），輸入代稱時即時顯示網址

不含：照片上傳、排序、刪除商品（後台第二階段，2026-10-21 決定分兩次做：這次改版完成後緊接著另開 `add-photo-upload`，不等部署）；登入頁改版（只套用新的字體與顏色）；前台任何頁面。

## Capabilities

### New Capabilities

（無）

### Modified Capabilities

- `product-admin`：
  - 「後台商品列表」多顯示封面縮圖、價格、精選排序、更新日期與狀態總覽
  - 「新增商品」輸入代稱時預覽網址
  - 「故事 Markdown 預覽」改成打字時自動預覽，並提供格式按鈕
  - 新增需求：編輯頁的資料完成度、編輯頁的商品照片、未儲存修改的提醒、後台在手機上可操作

## Impact

- 頁面：`JenJenKnits/Pages/Shared/_AdminLayout.cshtml`、`Pages/Admin/Index.cshtml(.cs)`、`Edit.cshtml(.cs)`、`Create.cshtml`、`Login.cshtml`（只受共用樣式影響）
- 樣式與互動：`wwwroot/css/admin.css`（大部分重寫）、`wwwroot/js/admin.js`
- 共用：「哪些欄位待補」的判斷從列表頁移出，列表與編輯頁共用
- 測試：`JenJenKnits.Tests/AdminProductTests.cs`；畫面互動（自動預覽、格式按鈕、未儲存提醒、手機版面）用無頭 Chrome 在 390px 與桌機寬度實際操作檢查
- 樣稿：`docs/design/admin-redesign/`（5 頁 HTML，瀏覽器直接打開）
- 不影響前台與 GitHub Pages 的輸出（後台不會被輸出）
